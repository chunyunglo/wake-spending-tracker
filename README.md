# Wake & Spending Tracker

A privacy-safe example project for maintaining daily wake-up and spending records and viewing wake-time trends in an interactive line chart.

## Usage

Open `index.html` to view the chart with synthetic demo data. The demo data is not copied from any real personal record.

Keep personal records on the local machine in files that are not tracked by Git. The `.gitignore` rules exclude the `university/` directory and the personal record filenames.

## Skill

`/.github/skills/wake-spending-tracker/SKILL.md` explains how to maintain local wake and spending records, calculate monthly totals, and update chart data without publishing personal information.

## Privacy

- Never commit real dates, wake times, spending amounts, names, local paths, or account identifiers.
- The public repository contains only source code, documentation, and synthetic demo data.
