# Wake & Spending Tracker

一個不含個人資料的範例專案：用每日輸入記錄起床時間與支出，並以互動式折線圖查看起床時間變化。

## 使用方式

直接開啟 `index.html` 即可查看示範圖表。專案內的資料是合成示範資料，不包含任何真實個人紀錄。

個人資料應留在本機，放在未納入 Git 的檔案中；`.gitignore` 已排除 `university/` 與個人紀錄檔名。

## Skill

`/.github/skills/wake-spending-tracker/SKILL.md` 說明如何在本機維護起床與支出紀錄、計算月總計，以及更新圖表資料。

## Privacy

- 不提交真實日期、起床時間、支出金額、姓名、路徑或帳號資訊。
- 公開 repo 僅包含程式碼、文件與合成示範資料。
